# Court character assets

Male Ranger and Male Peasant from **Modular Character Outfits – Fantasy (Standard)** by Quaternius.

- Source: https://quaternius.com/packs/modularcharacteroutfitsfantasy.html
- Download: https://quaternius.itch.io/modular-character-outfits-fantasy
- License: CC0 1.0; original notice is included in LICENSE.txt.
- Original authored clothing meshes, skin weights, skeletons, and textures are retained. Texture images were reduced to 768px for the web and stored as lossless WebP through EXT_texture_webp. The ranger's hood is hidden to leave the avatar mask visible.
- `Male_Head.glb` contains the head, neck, eyes, and eyebrows from the Standard edition of [Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) by Quaternius (CC0 1.0). The Superhero Male mesh is trimmed above the collar, re-centered on the shared `Head` joint, and packaged with cropped color textures. The application attaches each member's avatar mask to this head.
- The application supplies standing, seated, and kneeling skeletal poses, two-bone limb IK, avatar faces, and idle movement. Models are served locally, with no runtime dependency on an external asset host.
- The sovereign adds a custom chest-attached crimson coronation mantle with folded cloth, ermine trim, gold embroidery, a linked chain and a ruby clasp. Its tunic uses a crimson material; the ranger's shoulder armour is hidden.
